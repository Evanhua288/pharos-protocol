# 二、**步骤（手算／写码都行）**

## 步 1 · **每条先算自己的 `hash`**

**规则（`§3.0`）**：

```
hash = SHA-256( 前缀 ‖ JCS( 该条，不含 hash 键 ) )
前缀 = ASCII(prevHash)      ← 本账本 10 条的 prevHash 全部为 64 个 "0"
JCS  = RFC 8785（键名字典序、无空格、UTF-8）
```

**注意三条**：
- **`prevHash` **要保留在 JCS 里****（**`023`**）；
- **`hash` 键要被排除**（**`023`**）；
- **`what` 里有中文与一个 emoji**——**按 JCS 原样 UTF-8，不转义**。

**产出**：**10 个 `hash` 值**。

## 步 2 · **把这 10 条排成"规范序列"**

**规则（`125`／`126`）**：

```
主键：when     升序（ISO 8601 UTC 秒级，字符串比较即可）
次键：entryId  升序
```

**本账本里有三对同秒条目**（`…0001`/`…0002`、`…0004`/`…0005`、`…0007`/`…0008`）——
**它们必须靠你们的次键决定顺序**；**这就是本 fixture 的第一道考点**。

> ## ⏪ **V1.1 订正（承第二方 `WORKBUDDY-PH-071` 实测）——**本节的考点表述已改****：
> ## **\u3000\u3000**① **本文件的条目放置顺序，**故意**不是**规范序列****（**三对同秒条目在文件里各自**倒序****：`…0002` 在 `…0001` 前，等）
> ## **\u3000\u3000**\u3000\u3000**——**故"照文件原序直接用"者**必错****，**这一条**可证伪****。
> ## **\u3000\u3000**② ⏪ **V1.30 订正（承第二方 `WORKBUDDY-PH-076` §六第 1 条）**：**上一版本段写的"有没有写次键不可证伪"是**错的，已撤销****。
> ## **\u3000\u3000**\u3000\u3000**正确表述**：**本 fixture **可区分**"不排序／仅按 `when`"与"按 `125`／`126` 排序"**——
> ## **\u3000\u3000**\u3000\u3000**前者（不排序）得 `71cd93753f47b3843000c91b3372b95235497659a5764d42252280438836acbb`**；
> ## **\u3000\u3000**\u3000\u3000**后者（按 `125`／`126`）得 `9a9cc047027b41f92e9977899728fe2e3f0a17960da9d0734eb29326c901578d`** ⇒ **两者**不同值 ⇒ 可证伪****。
> ## **\u3000\u3000**③ **不可区分**的只剩**「`when` 与 `entryId` **全同**」**这一情形，**而它已由 `CORE-001-191` 覆盖**（**拒收报 `E01`**）。
> ## **\u3000\u3000**\u3000\u3000**（**我上一版的错因**：**把"稳定排序不重排并列项"当成了"排序会把三对内序调回来"**——**两件不同的事**。）**
> ## **\u3000\u3000**④ **若 `when` 与 `entryId` **全同****（**真重复条目**）⇒ **按 `CORE-001-191` **拒收并报 `E01`****（**不留未定义**）。
> ## **\u3000\u3000**⑤ **另**：**非 BMP 的排序口径**由 `vectors/NEGATIVE-CASES.md` 的 **`n05-sort-nonbmp`** 覆盖**（**`U+E000` vs `U+1F600`**）。

**产出**：**一个 10 条的次序**（**建议把你排出的 `entryId` 列表一并交出**）。

## 步 3 · **拼接后取一次 SHA-256**

**规则（`128`）**：

```
ledgerHash = SHA-256( ASCII("PHAROS-LEDGER-v1") ‖ ASCII( 步2 序列中每条的 hash，首尾相接 ) )
```

- **`ASCII("PHAROS-LEDGER-v1")` 有 16 字节**（**前缀，不是十六进制**）；
- **10 条 hash 首尾相接 ＝ 640 个 ASCII 字符**（**64 × 10**）；
- **不加任何分隔符**。

**产出**：**`ledgerHash`**。
