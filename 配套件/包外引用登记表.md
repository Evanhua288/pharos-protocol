# 三、**"未交付"的地位（**别被读成"不存在"**）**

| 状态 | 含义 | 接收方可以做什么 |
|---|---|---|
| **已交付** | **在包内且列于交付范围** | **可据以主张** |
| **未交付** | **包内没有，但被引用** | **可读、可参照，**不得据以主张对方违规**** |
| **不交付** | **明示不在交付范围** | **不得引用** |
| **已降格为沿革标注** | **仅供版本追溯** | **不得作为判定依据** |
