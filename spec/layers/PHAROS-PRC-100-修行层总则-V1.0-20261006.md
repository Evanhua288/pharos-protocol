## 1. 定位

**修行层回答一个问题**：**一个人的成长路径，在数字世界里如何被记录，而不被评判？**

> ## **位阶是"位置陈述"，不是"资质证书"。**

---

## 2. 四条前提（**不可削弱**）

| # | 前提 |
|---|---|
| **①** | **位阶不是等级**——**不排名、不比较、不显示他人位阶** |
| **②** | **位阶不带特权**——**不决定分配、话语权、优先权、准入门槛** |
| **③** | **只有本人能看见**——默认私密；公开须本人同意，**撤回即时生效** |
| **④** | ⭐ **凡判据不可测者，不得由系统自动判定**——只能"本人申报 ＋ 他人确认" |

**⚠️ 第四条是新增的，它解决一个真问题**：

> **原九阶里有几阶的判据（如"沉淀出稳定的判断框架""协同效率达标"）根本无法客观测量。**
> **把它们留给系统自动判定，等于**系统在替用户判断他的人生**——与"镜子不是尺子"直接冲突。**

---

## 3. 位阶定义（**九阶，双名制**）

| 阶 | 内部名（研发代号） | **对外名** | 状态 | 判定方式 |
|---|---|---|---|---|
| **一** | 淬体 | **接入期** | 本体数据开始汇聚 | 系统 |
| **二** | 炼气 | **记忆期** | 跨会话连续性建立 | 系统 |
| **三** | **筑基** | **成型期** | 数字主观世界成型、人格稳定 | 系统 ＋ **本人确认** |
| **四** | 金丹 | **成熟期** | 认知维度扩展、开始输出价值 | **本人申报 ＋ 他人确认** |
| **五** | 元婴 | **独立期** | 可独立承接任务、自主行动 | 系统 ＋ 本人 |
| **六** | 化神 | **互证期** | 数字与现实深度互证、跨节点 | 系统 |
| **七** | 合体 | **共修期** | 本体与数字主体认知共享 | **本人申报 ＋ 他人确认** |
| **八** | **传灯** | **利他期** | 服务社区、贡献价值 | **本人申报 ＋ 他人确认** |
| **九** | **交托** | **传承期** | **把关系与劳动交出去** | **本人 ＋ 继承人确认** |

### 3.1 三处命名修正（**逐条给理由**）

| 原 | 改 | 理由 |
|---|---|---|
| **大乘** | **传灯** | 大乘是佛教术语；**传灯保留东方语感且无宗教归属** |
| **渡劫** | **交托** | **把跨代传承（实际含身故）命名为"劫"是对逝者与家属的不尊重**，且与"不数字复活"紧邻；**交托**表达的是"把东西交出去" |
| 第九阶状态"**延续本体**" | "**把关系与劳动交出去**" | **"延续本体"在身故语境极易被读成数字永生** |

### 3.2 判定归属（**按第四条前提**）

| 阶 | 判定方式 | 为什么 |
|---|---|---|
| **一·二** | **系统可判** | 记录连续性、召回率、活跃度——都是行为数据 |
| **四·七** | **本人申报 ＋ 他人确认** | **判据不可测** |
| **五·六** | **系统可判** | 任务完成率；**跨节点任务记录可校验**（**⏪ V1.1 订正**：**原写“跨节点互认——可测”**，**与本件 `§6`「本层**不**互认」相冲**；**现改为“可校验”**（**只说记录可核，不说位阶可互认**）**） |
| **八·九** | **本人申报 ＋ 他人确认** | **教人、留物、托底，系统看不见** |

### 3.3 双名制

| 场合 | 用哪套 |
|---|---|
| **内部（规范／研发／文件）** | **内部名**（淬体／筑基…） |
| **对外（界面／宣讲／社媒）** | **对外名**（接入期／成型期…） |

**⚠️ 对外一律用对外名**——**避免宗教联想**。

## 4. 位阶的五条纪律

| # | 纪律 |
|---|---|
| **1** | **逐阶进，不跳阶** |
| **2** | **凡判据不可测者，必须"本人申报 ＋ 他人确认"** |
| **3** | **确认人须承担责任**（其确认记录可被追溯） |
| **4** | **长期不动显示"沉淀"状态，不降位**；恢复互动后可**原样接上** |
| **5** | **不得以分数阈值触发** |

## 5. 与相邻层的关系

| 相邻层 | 关系 |
|---|---|
| **L5 认知（COG）** | 位阶**不得**由认知维度自动推导；两者独立 |
| **L1 本体（ID）** | 传承交接**必须**承接 ID 层的三态规范（在世／失能／身故） |
| **L4 经济（FIN）** | 位阶**不得**作为计量与分配的入参 |
| **L7 意义（VAL）** | 位阶**不得**作为贡献记录的依据 |
| **红线规范（VAL-400）** | **冲突时以红线为准** |
