## 1. 范围与定位

### 1.1 认知层要回答的问题

> **一个人的"内在世界维度"，在数字世界里以什么形式存在，才能既被照见、又不被评判？**

### 1.2 答案

> ## **以"记录"形式存在，不以"分数"形式存在。**

### 1.3 定位（三条）

| # | 定位 |
|---|---|
| **1** | **只描述，不评判** |
| **2** | **只照见，不定义** |
| **3** | **只对本人，不对外** |

---

## 2. ⭐ 坐标 Profile 机制（**本规范的核心设计**）

### 2.1 核心条款

> ## **`PHAROS-COG-100-001`（必须）**
> **核心规范**必须**只规定"一个认知 Profile 必须提供什么"，**不得**规定"使用哪一套文明体系"。
> ## **`PHAROS-COG-100-002`（必须）**
> 任何认知坐标系**必须**以**可插拔 Profile** 的形式存在；**不得**写入核心规范。

### 2.2 一个合规 Profile 必须提供五件

| # | 要件 | 规范要求 |
|---|---|---|
| **①** | **坐标定义** | 这套体系怎么定位一个人（时间／方位／结构／关系，**任选**） |
| **②** | **输入清单** | 需要哪些数据，且 **这些数据不得来自行为画像的反推** |
| **③** | **输出三态** | **一致／偏离／冲突**——**不得输出吉凶、不得输出结论** |
| **④** | **可解释性** | **推演链可被本人查看**（算法可不开源，但**推演可复算**） |
| **⑤** | **禁语表** | 该 Profile 自己的禁语 |

**一致性测试 C-10**：Profile 注册项五项齐备方可通过。

### 2.3 为什么这样定位（**三条理由，写入规范注释**）

| # | 理由 |
|---|---|
| **1** | **法律上自洽**——协议中立、无国籍；把某文明写成"底层哲学"会与"排除某法域、实现按法域分区"的范围声明冲突 |
| **2** | **与多法域一致**——"属地只有附则、没有例外"；押注一个文明就排除了其余 |
| **3** | ⭐ **技术上反而更强**——既有正式口径是"**形式化**"（八卦＝3bit 状态空间、六爻＝六阶动态、五行＝生克网络、奇门＝时空约束优化），**可复算、可验证**；讲成"文明内核"就变成不可检验的信念 |

### 2.4 第一个实现

**`PHAROS-COG-100-A` ＝ 东方认知 Profile**（第一个实现，可最完整，**但不是唯一**）。

## 3. 认知层五条总则

| 条号 | 形态 | 条款 | 一致性测试 |
|---|---|---|---|
| **`COG-100-010`** | 必须 | 认知信息**必须**以"**维度 ＋ 记录**"形式存储与呈现 | C-1 |
| **`COG-100-011`** | 禁止 | **不得**生成任何**人级综合分**、**百分位**或**跨人排序** | C-1／C-2 |
| **`COG-100-012`** | 禁止 | 各维度之间**不得加权合成**为一个数值；**不得**定义为可比较的等级 | C-3 |
| **`COG-100-013`** | 可以 | **可以**统计单维度内"**本人自己**"的时间趋势，**前提是不含跨人比较** | C-2 |
| **`COG-100-014`** | 必须 | 认知数据**必须**默认仅本人可见；**必须**可导出、可迁移、可**真删除** | C-4／C-8 |

---

## 4. 与相邻层的接口

| 相邻层 | 接口内容 | 约束 |
|---|---|---|
| **L1 本体层（ID）** | **记忆边界与删除机制** | 认知记录的删除**必须**走 ID 层同一机制；**不留影子副本** |
| **L4 经济层（FIN）** | **计量轨** | 认知记录**不得**作为计量单位定价或分配的依据 |
| **L6 修行层（PRC）** | 位阶判定引用 | **凡判据不可测者，不得由系统判定**（见 `PRC-100`） |
| **L7 意义层（VAL）** | 三观与贡献 | 认知记录**不得**作为贡献或三观的输入 |
| **Profile 注册** | 坐标 Profile | 由基金会备案；变更报治理委员会 |

---

## 5. 禁语与越界总则

### 5.1 通用禁语（**凡实现均适用**，不因 Profile 不同而豁免）

**天机 ｜ 命理 ｜ 算命 ｜ 开运 ｜ 改运 ｜ 财运 ｜ 运势 ｜ 批八字 ｜ 风水 ｜ 吉凶 ｜ 命中注定**，以及**一切吉凶断定句式**与**命定句式**（"因为你是 X，所以你会 Y"）。

### 5.2 越界判定

| 条号 | 形态 | 条款 |
|---|---|---|
| **`COG-100-020`** | 禁止 | 认知层输出**不得**包含**预测、建议结论、吉凶** |
| **`COG-100-021`** | 禁止 | 认知层数据**不得**用于**社会信用、信贷、就业、保险、准入** |
| **`COG-100-022`** | 必须 | 命理类内容**不得金融化**——**不得**用于投资、借贷、彩票、改运承诺 |

**一致性测试 C-7**：输出全量扫描，零禁语、零命定句式、零吉凶断定。

## 6. 可关闭与可撤回（**本层的同意机制**）

| 条号 | 形态 | 条款 |
|---|---|---|
| **`COG-100-030`** | 必须 | 实现**必须**提供"**关闭认知线**"的开关；关闭后**不得**继续采集坐标线输入 |
| **`COG-100-031`** | 必须 | 关闭**不得**影响任何其它层功能 |
| **`COG-100-032`** | 必须 | 关闭后**已有记录必须仍可查看与导出** |

## 8. 失败与降级

| 情形 | 处置 |
|---|---|
| **C-1／C-2／C-3 不通过** | **不合规**——立即停用认知层 |
| **C-7 不通过** | **立即下线相关输出** |
| **C-4 不通过** | **立即停用对外展示** |
| **未注册 Profile 而输出坐标** | **视为越界**——须停用 |

## 9. 版本与分叉

| 情形 | 规则 |
|---|---|
| **本规范升版** | 语义化版本；**Core 只加不改** |
| **Profile 变更** | 由该 Profile 的实现方共同维护，报治理委员会备案 |
| **分叉** | **允许分叉，但分叉方不得自称 PHAROS** |
| **谁能改 Core** | 协议托管方（当前为 AETHEL Foundation） 持标准 ＋ 治理委员会批准 |

## 10. 诚实边界

- 本规范为**技术规范草案**，**不构成法律、宗教或合规意见**；
- **"形式化口径"的可复算性须技术侧确认**；
- **东方认知 Profile（`COG-100-A`）的合规边界须外部法律意见**；
- **涉脆弱人群的保护条款见 `COG-400`**；
- 证据截止 **2026-10-06**。
