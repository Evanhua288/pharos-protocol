## 1. 六维定义（**规范性**）

| 维 | 定义（协议原文） | **用户侧表达（规定话术）** | **禁止表述** |
|---|---|---|---|
| **广度** | 接触过的领域、文化、观点、人群 | "你在 N 个领域有记录" | "你的认知得分 78" |
| **深度** | 对某领域的理解程度与洞察 | "这条线持续了 N 年" | "你比 80% 的人专注" |
| **可延展性** | 跨域迁移与创新记录 | "你从 X 领域迁移到了 Y 领域" | "你的迁移能力是 A 级" |
| **稳定度** | 承诺与交付的吻合度 | "你在压力下还立得住" | "你的稳定性排名前 10%" |
| **自省性** | 认知与选择的迭代记录 | "你修正了之前的判断" | "你的自省得分 85" |
| **共生性** | 协作网络的质量与稳定性 | "你与 X 社区保持了 3 年协作" | "你的共生性 B+" |

**一致性测试 C-7**：用户侧表达**必须**落在"话术列"之内；不得出现"禁止表述"列的任何形式。

## 2. 关键条款（**完整规范写法**）

### 2.1 存储与呈现

> **`PHAROS-COG-200-001`（必须）**
> 实现**必须**以"**维度 ＋ 记录**"的形式存储与呈现认知信息。
> **一致性测试 C-1**：数据结构审查；维度字段为枚举，记录为数组。

### 2.2 禁止人级综合分

> **`PHAROS-COG-200-002`（禁止）**
> 实现**不得**生成任何形式的**人级综合分**（composite score）、**百分位**（percentile）或**跨人排序**。
> **一致性测试 C-1／C-2**：全库 schema 与 API 扫描；不存在 `score/grade/level/percentile/rank/composite/weight`。

### 2.3 禁止维度间加权

> **`PHAROS-COG-200-003`（禁止）**
> 六个维度之间**不得加权合成**为一个数值；**不得**定义为可比较的等级。
> **一致性测试 C-3**：验证不存在跨维度聚合端点；验证维度权重配置不存在。

### 2.4 允许本人时间趋势

> **`PHAROS-COG-200-004`（可以）**
> 实现**可以**统计单一维度内"**本人自己**"的时间趋势（如"比上月多了 3 条记录"），
> **前提**：该统计**不得**包含跨人比较、**不得**包含百分位、**不得**构成任何形式的等级暗示。
> **一致性测试 C-2**：验证该端点返回结果**不含**任何其他主体标识。

### 2.5 维度不得作为分配依据

> **`PHAROS-COG-200-005`（禁止）**
> 任一维度**不得**作为以下判定的输入：**任务分配、结算优先级、投票权重、身份等级、可见范围**。
> **一致性测试 C-3**：置空对照实验——将全部维度字段置空后，上述五类判定结果**不变**。

## 3. 六维的计分禁令（**汇总**）

| 🔴 禁止 | 说明 |
|---|---|
| **单一维度分值** | 如"广度 72 分" |
| **跨维加权总分** | 如"综合认知分 68" |
| **百分位** | 如"超越 87% 的用户" |
| **等级** | 如"延展性 B+""段位" |
| **可比较的量化** | 任何可用于横比的数值 |

**⚠️ 常见规避手法（须重点查）**：

| # | 手法 |
|---|---|
| **1** | **改名叫"完成度""活跃度""成长值"** |
| **2** | **用颜色深浅或图表代替数字排名** |
| **3** | **用"你超过了 N 位用户"隐式排名** |
| **4** | **用星级、徽章、称号暗示等级** |

## 4. 呈现规则

| 条号 | 形态 | 条款 |
|---|---|---|
| **`COG-200-010`** | 必须 | 默认**仅本人可见**；对外展示需**逐次授权**（**不是一次授权长期有效**） |
| **`COG-200-011`** | 必须 | 对外展示**只展示路径，不展示数值** |
| **`COG-200-012`** | 必须 | 跨节点读取需**双向授权**（对方亦同意） |
| **`COG-200-013`** | 必须 | 认知记录**必须**可导出、可迁移、可**真删除**（不留影子副本） |

**一致性测试 C-4／C-8**。

## 5. 数据模型

```
CognitionRecord {
  subject:     DID                    // 只有本人
  dimension:   ENUM(breadth | depth | extensibility
                    | stability | reflexivity | symbiosis)
  records:     [ { when, evidenceRef, note } ]
  profileId:   STRING | null          // 哪套坐标 Profile
  visibility:  ENUM(private | member | public)   // 默认 private
}

// ── 禁止存在的字段（一致性测试逐字段扫描）──
FORBIDDEN: score · grade · level · percentile · rank
           composite · weight · points · badge · title
```

**⚠️ 说明**：**`badge`（徽章）与 `title`（称号）亦列入禁止**——**它们是等级的常见伪装。**
